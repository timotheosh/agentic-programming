* Purpose

This document is a copy-ready template for a Hermes Agent development workflow in which:

1. =test-designer= independently translates requirements into executable behavioral tests and proves RED.
2. =implementer= uses ACD principles to produce the smallest coherent implementation that makes the tests GREEN.
3. =correctness-reviewer= checks requirements, tests, coverage, and behavior.
4. =structural-reviewer= checks duplication, contracts, schemas/specs, complexity, and maintainability.
5. =flow-documenter= documents the final approved runtime flow in Draw.io.

The two reviewers form a fail-closed AND gate. Neither reviewer may edit files. Each implementation slice must pass that gate, but =flow-documenter= runs only once: after every planned slice is complete and both reviewers approve the final integrated revision. The overall task is complete only when that final flow documentation is complete.

Unlike the companion Claude Code workflow, Hermes agents are independent =hermes chat= processes. The orchestrator supplies requirements and current task data explicitly, and persists every agent result and workflow transition on disk. Each agent can run with its own model, provider, turn budget, and toolset — configured in a single YAML file.

* Operating model

#+begin_example
Requirements and planned slices
              │
              ▼
  ┌──── repeat for each slice ────┐
  │ test-designer → verified RED  │
  │              │                │
  │              ▼                │
  │ implementer + ACD → GREEN     │
  │              │                │
  │              ▼                │
  │ correctness + structural      │
  │ reviewers → dual approval     │
  └──────────────┬────────────────┘
                 │ all slices complete and
                 │ final revision approved
                 │
                 ▼
          flow-documenter (once)
                 │
                 └── docs/<feature>-flow.drawio
#+end_example

Reviewers run sequentially against the same explicitly fingerprinted working tree. The orchestrator detects changes to non-pipeline working-tree content and protected workflow artifacts and invalidates the review. Automatic Hermes worktrees are intentionally unsupported because they may start from the remote tip and omit the active dirty implementation and ignored workflow artifacts.

The standalone Python orchestrator (=orchestrator.py=) coordinates all stages. Every invocation captures and durably logs exit status, stdout, stderr, and elapsed time. Machine-owned state records the requirements hash, slice plan, stage outcomes, findings, exact working-tree fingerprint, and final documentation status.

## Workflow-specific implementation constraints

Never delete, skip, weaken, or rewrite an independent behavioral test merely to get GREEN. If a test contradicts the requirement or encodes an invalid assumption, stop and report the exact test, requirement, conflict, and proposed resolution to the orchestrator.

Coverage and contract requirements:
- Give calculation and business-rule functions meaningful behavioral coverage, including important branches and boundary cases. Raw line coverage alone is insufficient.
- Add implementation-specific unit tests when they add confidence without coupling to incidental structure.
- Give data crossing meaningful external, persistence, API, event, or domain boundaries an explicit contract.
- In Clojure, use `clojure.spec` or the repository's established schema library. Do not spec every trivial local value.
- In other languages, use the repository's established type, schema, or validation mechanism.
- Validate at boundaries and provide useful failure information.

Search the repository before introducing helpers, abstractions, schemas/specs, or test infrastructure. Remove duplication only when the shared concept is stable and the result is clearer.

Run the focused tests during development, then the complete relevant suite, linters/static checks, and the repository's coverage command when available. Do not claim GREEN if unrelated relevant tests fail.

Write `.ai/implementation-report.md` with:
- requirement and revision/diff reviewed;
- files changed and why;
- test and check commands with results;
- meaningful coverage for calculation/business logic;
- specs, schemas, types, or validators added/changed;
- existing code reused and duplication considered;
- assumptions, risks, and unresolved issues.

`.ai/workflow/current.md` is owned by the orchestrator; do not edit it. Stop at GREEN. Your entire final response must be exactly one JSON code block with `status` equal to `GREEN`, a nonempty `evidence` string, and an `artifact` naming `.ai/implementation-report.md`. If blocked or the relevant suite is not GREEN, exit nonzero instead of reporting success. Do not approve your own work and do not invoke final documentation.

* Copy into =orchestrator.py=

The orchestrator is a standalone Python script. Run it with =python .hermes/pipeline/orchestrator.py docs/spec.md=. The requirements file is a mandatory positional CLI argument, resolved relative to the project root unless absolute. Repeat =--slice DESCRIPTION= to define an ordered slice plan; otherwise the entire feature is one slice. =--project= defaults to =PIPELINE_PROJECT= or the current working directory. =--feature= defaults to =PIPELINE_FEATURE= or the requirements filename without extension. =--hermes= defaults to =HERMES_EXECUTABLE=, then a =hermes= found on =PATH=, then =~/.local/bin/hermes=. Python, PyYAML, Git, and the Hermes CLI are required.

Each agent runs as an independent =hermes chat= process. The orchestrator writes the prompt to a temp file (passed via =--query-file= — never shell-interpolated), spawns the process, captures exit code / stdout / stderr / elapsed time, and validates that the required artifact exists before proceeding to the next stage.

Reviewer stdout is atomically persisted by the orchestrator and parsed as exactly one fenced JSON object. Malformed, missing, ambiguous, failed-process, or non-JSON output blocks the pipeline. Verdicts are validated against a full commit-plus-working-tree fingerprint to prevent stale approvals.

def resolve_hermes_executable(requested):
    """Resolve the Hermes CLI without assuming interactive-shell PATH setup."""
    if requested:
        resolved = shutil.which(requested)
        if resolved:
            return resolved
        expanded = os.path.abspath(os.path.expanduser(requested))
        if os.path.isfile(expanded) and os.access(expanded, os.X_OK):
            return expanded
        parser.error(f"Hermes executable is not executable or was not found: {requested}")

    resolved = shutil.which("hermes")
    if resolved:
        return resolved
    local_install = os.path.expanduser("~/.local/bin/hermes")
    if os.path.isfile(local_install) and os.access(local_install, os.X_OK):
        return os.path.abspath(local_install)
    parser.error("Hermes executable was not found on PATH or at ~/.local/bin/hermes; "
                 "pass --hermes PATH or set HERMES_EXECUTABLE")

# ── Agent Runner ──

def run_agent(role, task, extra_context="", worktree=False):
    """Spawn a Hermes agent as an independent process.

    Returns dict with exit_code, stdout, stderr, elapsed_s, success, timeout.
    """
    cfg = AGENTS.get(role, {})
    model = cfg.get("model")
    provider = cfg.get("provider")
    max_turns = cfg.get("max_turns", 100)
    run_budget = cfg.get("run_budget")
    reasoning = cfg.get("reasoning")
    toolsets = cfg.get("toolsets")
    timeout = SETTINGS.get("agent_timeout_seconds", 900)

    # Load role prompt
    prompt_file = f"{PROJECT}/.hermes/pipeline/prompts/{role}.md"
    with open(prompt_file, encoding="utf-8") as f:
        system_prompt = f.read()

    full_prompt = f"""{system_prompt}

## Task
{task}

## Context
Project: {PROJECT}
Feature: {FEATURE}
{extra_context}
"""

    # Write prompt to temp file — safe: no shell interpolation
    with tempfile.NamedTemporaryFile(mode="w", encoding="utf-8", suffix=".md", delete=False) as tf:
        tf.write(full_prompt)
        prompt_path = tf.name

    cmd = [HERMES_EXECUTABLE, "chat", "--query-file", prompt_path,
           "--oneshot", "-Q", "--in", PROJECT,
           "--max-turns", str(max_turns)]
    if model:
        cmd.extend(["--model", model])
    if provider:
        cmd.extend(["--provider", provider])
    if run_budget:
        cmd.extend(["--run-budget", str(run_budget)])
    if reasoning:
        cmd.extend(["--reasoning", reasoning])
    if toolsets:
        cmd.extend(["--toolsets", toolsets])
    if worktree:
        cmd.append("--worktree")

    t0 = time.monotonic()
    timed_out = False
    try:
        result = subprocess.run(cmd, cwd=PROJECT, capture_output=True,
                                text=True, encoding="utf-8", errors="replace", timeout=timeout)
        exit_code, stdout, stderr = result.returncode, result.stdout, result.stderr
    except subprocess.TimeoutExpired as exc:
        exit_code, stdout, stderr = 124, _output_text(exc.stdout), _output_text(exc.stderr)
        timed_out = True
    except OSError as exc:
        exit_code, stdout, stderr = None, "", str(exc)
    finally:
        elapsed = time.monotonic() - t0
        try:
            os.unlink(prompt_path)
        except OSError:
            pass

    return {
        "role": role,
        "command": cmd,
        "prompt": full_prompt,
        "exit_code": exit_code,
        "stdout": stdout,
        "stderr": stderr,
        "elapsed_s": round(elapsed, 1),
        "timeout": timed_out,
        "success": exit_code == 0,
    }


def _output_text(output):
    """Normalize partial subprocess output, which can be bytes on timeout."""
    return output.decode("utf-8", errors="replace") if isinstance(output, bytes) else output or ""


# ── Response Calculations ──

def parse_json_response(content):
    """Parse exactly one fenced JSON object with no surrounding output."""
    if not isinstance(content, str):
        return None
    match = re.fullmatch(r"\s*```(?:json)?[ \t]*\n(.*?)\n```\s*", content, re.DOTALL)
    if not match:
        return None
    try:
        value = json.loads(match.group(1))
    except json.JSONDecodeError:
        return None
    return value if isinstance(value, dict) else None

def parse_review_json(filepath):
    """Read and strictly parse one reviewer response artifact."""
    try:
        with open(filepath, encoding="utf-8") as f:
            content = f.read()
    except (OSError, UnicodeError):
        return None
    return parse_json_response(content)


def validate_verdict(verdict, expected_revision, role=None):
    """Validate the complete reviewer contract as a pure calculation."""
    if not isinstance(verdict, dict):
        return {"valid": False, "reason": "response is not a JSON object"}
    if verdict.get("verdict") not in ("APPROVE", "REQUEST_CHANGES"):
        return {"valid": False, "reason": "missing or invalid 'verdict'"}
    if verdict.get("revision") != expected_revision:
        return {"valid": False, "reason":
                f"revision mismatch: {verdict.get('revision')} vs {expected_revision}"}
    if not isinstance(verdict.get("evidence"), str) or not verdict["evidence"].strip():
        return {"valid": False, "reason": "missing or empty 'evidence'"}
    findings = verdict.get("findings")
    if not isinstance(findings, list):
        return {"valid": False, "reason": "'findings' must be a list"}
    if verdict["verdict"] == "APPROVE" and findings:
        return {"valid": False, "reason": "APPROVE must contain no findings"}
    if verdict["verdict"] == "REQUEST_CHANGES" and not findings:
        return {"valid": False, "reason": "REQUEST_CHANGES requires findings"}
    required = {"id", "owner", "location", "evidence", "why", "required_outcome"}
    if role == "correctness-reviewer":
        required.add("requirement")
    for index, finding in enumerate(findings):
        if not isinstance(finding, dict):
            return {"valid": False, "reason": f"finding {index + 1} is not an object"}
        missing = [key for key in required
                   if not isinstance(finding.get(key), str) or not finding[key].strip()]
        if missing:
            return {"valid": False, "reason": f"finding {index + 1} missing: {', '.join(sorted(missing))}"}
        if finding["owner"] not in ("test-designer", "implementer", "both"):
            return {"valid": False, "reason": f"finding {index + 1} has invalid owner"}
    return {"valid": True, "verdict": verdict["verdict"], "findings": findings}


def validate_stage_response(content, expected_status, expected_revision=None):
    response = parse_json_response(content)
    if response is None:
        return {"valid": False, "reason": "output is not exactly one fenced JSON object"}
    if response.get("status") != expected_status:
        return {"valid": False, "reason": f"expected {expected_status}, got {response.get('status')}"}
    if not isinstance(response.get("evidence"), str) or not response["evidence"].strip():
        return {"valid": False, "reason": "missing or empty evidence"}
    if expected_revision is not None and response.get("revision") != expected_revision:
        return {"valid": False, "reason": "revision does not match the approved snapshot"}
    return {"valid": True, "response": response}

class StageFailed(Exception):

def verify_artifact(path, description):
    if not os.path.isfile(path):
        raise StageFailed(f"{description} not found: {path}")
    if os.path.getsize(path) == 0:
        raise StageFailed(f"{description} is empty: {path}")
    print(f"  OK: {description}")


def _atomic_write(path, content):
    os.makedirs(os.path.dirname(path), exist_ok=True)
    descriptor, temporary = tempfile.mkstemp(prefix=".pipeline-", dir=os.path.dirname(path))
    try:
        with os.fdopen(descriptor, "w", encoding="utf-8") as stream:
            stream.write(content)
            stream.flush()
            os.fsync(stream.fileno())
        os.replace(temporary, path)
    finally:
        if os.path.exists(temporary):
            os.unlink(temporary)


def _archive_artifact(path):
    if not os.path.lexists(path):
        return
    if not os.path.isfile(path):
        raise StageFailed(f"refusing to replace non-file artifact: {path}")
    archive = os.path.join(WORKFLOW_DIR, "archive", FEATURE_KEY)
    os.makedirs(archive, exist_ok=True)
    stamp = datetime.datetime.now(datetime.timezone.utc).strftime("%Y%m%dT%H%M%S.%fZ")
    os.replace(path, os.path.join(archive, f"{stamp}-{os.path.basename(path)}"))


def _new_state():
    return {
        "version": 1, "feature": FEATURE, "requirements_path": os.path.abspath(reqs_path),
        "requirements_sha256": hashlib.sha256(REQUIREMENTS.encode()).hexdigest(),
        "status": "IN_PROGRESS", "current_slice": 0,
        "slices": [{"name": name, "status": "NOT_STARTED", "test_design": "NOT_STARTED",
                    "implementation": "NOT_STARTED", "review_round": 0,
                    "needs_repair": False, "findings": [], "revision": None}
                   for name in SLICES],
        "flow_documentation": {"status": "NOT_STARTED", "path": FLOW_PATH, "revision": None},
        "history": [],
    }


def _save_state(state, event=None):
    if event:
        state["history"].append({"at": datetime.datetime.now(datetime.timezone.utc).isoformat(),
                                 "event": event})
    serialized = json.dumps(state, indent=2, sort_keys=True)
    _atomic_write(STATE_PATH, serialized + "\n")
    _atomic_write(CURRENT_STATE_PATH,
                  f"# Workflow state: {FEATURE}\n\nMachine-owned; agents must not edit.\n\n```json\n{serialized}\n```\n")


def _load_state():
    identity = hashlib.sha256(REQUIREMENTS.encode()).hexdigest()
    if not os.path.exists(STATE_PATH):
        state = _new_state()
        _save_state(state, "pipeline initialized")
        return state
    try:
        with open(STATE_PATH, encoding="utf-8") as stream:
            state = json.load(stream)
    except (OSError, UnicodeError, json.JSONDecodeError) as exc:
        raise StageFailed(f"cannot resume invalid state: {exc}") from exc
    if (not isinstance(state, dict) or not isinstance(state.get("slices"), list)
            or not state["slices"] or not all(isinstance(item, dict) for item in state["slices"])
            or not isinstance(state.get("flow_documentation"), dict)
            or not isinstance(state.get("history"), list)):
        raise StageFailed("cannot resume: workflow state has an invalid schema")
    actual = (state.get("version"), state.get("feature"), state.get("requirements_path"),
              state.get("requirements_sha256"), [item.get("name") for item in state.get("slices", [])])
    expected = (1, FEATURE, os.path.abspath(reqs_path), identity, SLICES)
    if actual != expected:
        raise StageFailed("saved state does not match this feature, requirements file, or slice plan")
    _save_state(state, "pipeline resumed")
    return state


@contextlib.contextmanager
def _pipeline_lock():
    os.makedirs(WORKFLOW_DIR, exist_ok=True)
    with open(LOCK_PATH, "a+", encoding="utf-8") as lock:
        try:
            if fcntl is not None:
                fcntl.flock(lock.fileno(), fcntl.LOCK_EX | fcntl.LOCK_NB)
            else:
                lock.seek(0)
                if not lock.read(1):
                    lock.write("0")
                    lock.flush()
                lock.seek(0)
                msvcrt.locking(lock.fileno(), msvcrt.LK_NBLCK, 1)
        except (BlockingIOError, OSError) as exc:
            raise StageFailed("another Hermes pipeline is already running") from exc
        try:
            yield
        finally:
            if fcntl is None:
                lock.seek(0)
                msvcrt.locking(lock.fileno(), msvcrt.LK_UNLCK, 1)


def _run_git(*arguments):
    result = subprocess.run(["git", *arguments], cwd=PROJECT, capture_output=True)
    if result.returncode != 0:
        raise StageFailed(_output_text(result.stderr).strip() or "Git command failed")
    return result.stdout


class _HashWriter:
    def __init__(self, digest):
        self.digest = digest
    def write(self, value):
        self.digest.update(value)
        return len(value)


def _get_revision():
    """Return an identity for HEAD and all non-pipeline working-tree content."""
    head = _run_git("rev-parse", "HEAD").decode().strip()
    digest = hashlib.sha256()
    digest.update(_run_git("diff", "--binary", "HEAD", "--", ".", ":(exclude).ai",
                           f":(exclude)docs/{FEATURE_KEY}-flow.drawio"))
    untracked = _run_git("ls-files", "--others", "--exclude-standard", "-z", "--", ".").split(b"\0")
    for encoded in sorted(value for value in untracked if value):
        relative = encoded.decode("utf-8", errors="surrogateescape")
        if relative.startswith(".ai/") or relative == f"docs/{FEATURE_KEY}-flow.drawio":
            continue
        path = os.path.join(PROJECT, relative)
        digest.update(encoded + b"\0")
        if os.path.islink(path):
            digest.update(os.readlink(path).encode(errors="surrogateescape"))
        else:
            with open(path, "rb") as stream:
                shutil.copyfileobj(stream, _HashWriter(digest))
    return f"{head}:{digest.hexdigest()}"


def _protected_artifact_identity():
    """Fingerprint machine inputs a read-only reviewer must not change."""
    digest = hashlib.sha256()
    paths = [os.path.join(AI_DIR, "test-plan.md"),
             os.path.join(AI_DIR, "implementation-report.md"),
             STATE_PATH, CURRENT_STATE_PATH]
    for path in paths:
        digest.update(path.encode() + b"\0")
        if not os.path.isfile(path):
            digest.update(b"missing\0")
            continue
        with open(path, "rb") as stream:
            shutil.copyfileobj(stream, _HashWriter(digest))
    return digest.hexdigest()


def _record_agent(result):
    directory = os.path.join(WORKFLOW_DIR, "logs", FEATURE_KEY)
    stamp = datetime.datetime.now(datetime.timezone.utc).strftime("%Y%m%dT%H%M%S.%fZ")
    base = os.path.join(directory, f"{stamp}-{result['role']}")
    _atomic_write(base + ".prompt.md", result["prompt"])
    _atomic_write(base + ".stdout.md", result["stdout"])
    _atomic_write(base + ".stderr.txt", result["stderr"])
    metadata = {key: value for key, value in result.items() if key not in ("prompt", "stdout", "stderr")}
    _atomic_write(base + ".json", json.dumps(metadata, indent=2, sort_keys=True) + "\n")


def _invoke(role, task, expected_status=None, expected_revision=None):
    result = run_agent(role, task)
    _record_agent(result)
    _report_agent(result)
    if not result["success"]:
        raise StageFailed(f"{role} failed")
    if expected_status:
        checked = validate_stage_response(result["stdout"], expected_status, expected_revision)
        if not checked["valid"]:
            raise StageFailed(f"{role} returned invalid outcome: {checked['reason']}")
    return result


def _invoke_reviewer(role, task):
    before = _get_revision()
    protected_before = _protected_artifact_identity()
    result = run_agent(role, task)
    _record_agent(result)
    _report_agent(result)
    if _get_revision() != before:
        raise StageFailed(f"read-only reviewer {role} changed the working tree")
    if _protected_artifact_identity() != protected_before:
        raise StageFailed(f"read-only reviewer {role} changed protected workflow artifacts")
    if not result["success"]:
        raise StageFailed(f"{role} failed")
    return result

def run_pipeline():
    print(f"Pipeline: {FEATURE}")
    print(f"Project:  {PROJECT}")
    print(f"Config:   {CONFIG_PATH}")
    print()

    os.makedirs(REVIEWS_DIR, exist_ok=True)
    state = _load_state()
    if state["status"] == "COMPLETE":
        expected = state["flow_documentation"].get("revision")
        try:
            verify_artifact(FLOW_PATH, "Draw.io flow documentation")
            verify_artifact(os.path.join(REVIEWS_DIR, "correctness.md"), "correctness review")
            verify_artifact(os.path.join(REVIEWS_DIR, "structural.md"), "structural review")
            unchanged = (expected == _get_revision()
                         and ET.parse(FLOW_PATH).getroot().tag == "mxfile")
        except (StageFailed, ET.ParseError):
            unchanged = False
        if unchanged:
            print("Pipeline already complete; approved implementation is unchanged.")
            return True
        state["status"] = "IN_PROGRESS"
        state["flow_documentation"]["status"] = "NOT_STARTED"
        state["slices"][-1]["status"] = "IMPLEMENTED"
        state["slices"][-1]["revision"] = None
        _save_state(state, "completed pipeline invalidated by implementation or artifact change")

    for index, item in enumerate(state["slices"]):
        if item["status"] == "APPROVED":
            continue
        state["current_slice"] = index
        state["status"] = "IN_PROGRESS"
        slice_name = item["name"]
        print(f"─── Slice {index + 1}/{len(state['slices'])}: {slice_name} ───")

        try:
            if item["test_design"] != "COMPLETE":
                item["test_design"] = "IN_PROGRESS"
                _save_state(state, f"test design started: {slice_name}")
                plan = os.path.join(AI_DIR, "test-plan.md")
                _archive_artifact(plan)
                _invoke("test-designer",
                    f"Design tests for this slice: {slice_name}.\n\nOriginal requirements:\n{REQUIREMENTS}",
                    "RED_VERIFIED")
                verify_artifact(plan, "fresh test plan")
                item["test_design"] = "COMPLETE"
                _save_state(state, f"RED verified: {slice_name}")

            if item["implementation"] != "COMPLETE":
                item["implementation"] = "IN_PROGRESS"
                _save_state(state, f"implementation started: {slice_name}")
                report = os.path.join(AI_DIR, "implementation-report.md")
                _archive_artifact(report)
                _invoke("implementer",
                    f"Implement this slice and make the complete relevant suite GREEN: {slice_name}.\n\n"
                    f"Original requirements:\n{REQUIREMENTS}", "GREEN")
                verify_artifact(report, "fresh implementation report")
                item["implementation"] = "COMPLETE"
                _save_state(state, f"GREEN verified: {slice_name}")

            while item["status"] != "APPROVED":
                if item["needs_repair"]:
                    _repair_slice(state, item, REQUIREMENTS)
                if item["review_round"] >= MAX_REVIEW_ROUNDS:
                    raise StageFailed(f"exceeded {MAX_REVIEW_ROUNDS} review rounds")
                _review_slice(state, item, REQUIREMENTS)
        except StageFailed:
            item["status"] = "BLOCKED"
            state["status"] = "BLOCKED"
            _save_state(state, f"slice blocked: {slice_name}")
            raise

    final_revision = _get_revision()
    if state["slices"][-1]["revision"] != final_revision:
        last = state["slices"][-1]
        if last["review_round"] >= MAX_REVIEW_ROUNDS:
            raise StageFailed("working tree changed after final approval and no review rounds remain")
        last.update(status="IMPLEMENTED", revision=None)
        _save_state(state, "final approval invalidated by working-tree change")
        _review_slice(state, last, REQUIREMENTS)
        if last["status"] != "APPROVED":
            raise StageFailed("final integrated revision was not approved")
        final_revision = _get_revision()
    flow = state["flow_documentation"]
    if flow["status"] != "COMPLETE":
        flow["status"] = "IN_PROGRESS"
        state["status"] = "IN_PROGRESS"
        _save_state(state, "final flow documentation started")
        _archive_artifact(FLOW_PATH)
        result = _invoke("flow-documenter",
            f"Document the final approved implementation.\nExpected revision: {final_revision}\n"
            f"Required output file: {FLOW_PATH}\n\nOriginal requirements:\n{REQUIREMENTS}",
            "COMPLETE", final_revision)
        verify_artifact(FLOW_PATH, "Draw.io flow documentation")
        try:
            if ET.parse(FLOW_PATH).getroot().tag != "mxfile":
                raise ValueError("root element is not mxfile")
        except (ET.ParseError, ValueError) as exc:
            raise StageFailed(f"invalid Draw.io XML: {exc}") from exc
        if _get_revision() != final_revision:
            raise StageFailed("implementation changed during final documentation")
        flow.update(status="COMPLETE", revision=final_revision)
        state["status"] = "COMPLETE"
        _save_state(state, "pipeline complete")
    print("═══ PIPELINE COMPLETE ═══")
    return True


def _review_slice(state, item, requirements):
    item["review_round"] += 1
    revision = _get_revision()
    item["revision"] = revision
    item["status"] = "IN_REVIEW"
    _save_state(state, f"review round {item['review_round']} started for {item['name']}")
    results = []
    roles = (("correctness-reviewer", "correctness.md"),
             ("structural-reviewer", "structural.md"))
    for role, filename in roles:
        result = _invoke_reviewer(role,
            f"Review slice: {item['name']}.\nExpected revision (copy exactly): {revision}\n\n"
            f"Original requirements:\n{requirements}")
        artifact = os.path.join(REVIEWS_DIR, filename)
        _atomic_write(artifact, result["stdout"])
        verdict = validate_verdict(parse_review_json(artifact), revision, role)
        if not verdict["valid"]:
            raise StageFailed(f"{role} returned invalid verdict: {verdict['reason']}")
        results.append(verdict)
    if _get_revision() != revision:
        raise StageFailed("working tree changed during review")
    if all(result["verdict"] == "APPROVE" for result in results):
        item.update(status="APPROVED", needs_repair=False, findings=[], revision=revision)
        _save_state(state, f"dual approval: {item['name']}")
        return
    item["findings"] = [finding for result in results for finding in result["findings"]]
    item["needs_repair"] = True
    item["status"] = "REQUEST_CHANGES"
    _save_state(state, f"changes requested: {item['name']}")


def _repair_slice(state, item, requirements):
    findings = item["findings"]
    owners = {finding["owner"] for finding in findings}
    if owners & {"test-designer", "both"}:
        plan = os.path.join(AI_DIR, "test-plan.md")
        _archive_artifact(plan)
        _invoke("test-designer",
            f"Update tests for review findings on {item['name']}.\nFindings:\n"
            f"{json.dumps(findings, indent=2)}\n\nOriginal requirements:\n{requirements}",
            "TESTS_UPDATED")
        verify_artifact(plan, "fresh repaired test plan")
    if owners & {"implementer", "both", "test-designer"}:
        report = os.path.join(AI_DIR, "implementation-report.md")
        _archive_artifact(report)
        _invoke("implementer",
            f"Repair {item['name']} and make the complete relevant suite GREEN.\nFindings:\n"
            f"{json.dumps(findings, indent=2)}\n\nOriginal requirements:\n{requirements}", "GREEN")
        verify_artifact(report, "fresh repaired implementation report")
    item.update(needs_repair=False, findings=[], status="IMPLEMENTED", revision=None)
    _save_state(state, f"repairs complete: {item['name']}")


def _report_agent(result):
    status = "OK" if result["success"] else ("TIMEOUT" if result["timeout"] else "FAILED")
    print(f"  [{status}] {result['role']}: exit={result['exit_code']} "
          f"elapsed={result['elapsed_s']}s")
    if not result["success"]:
        stderr_preview = result["stderr"][:200] if result["stderr"] else "(no stderr)"
        print(f"         stderr: {stderr_preview}")

* Reviewer verdict contract

** JSON schema

Every reviewer must output a single JSON object as the final content before exit. The orchestrator parses this JSON mechanically — it never scans prose for verdicts.

      "id": "C1",
      "owner": "test-designer | implementer | both",

** Rules

- =verdict= is required. =APPROVE= only when =findings= contains no blocking items.
- =revision= is required. It must copy the complete snapshot identity supplied by the orchestrator; any mismatch blocks the pipeline.
- =findings= may be empty (clean approval). Every finding must include all fields.
- Structural reviewers must also include =duplicate_of= in findings when applicable.
- Malformed, missing, or non-JSON output is =REQUEST_CHANGES= — fail closed.

* Review and repair protocol

** Verdict contract

Each reviewer output is parsed as JSON. The following outcomes are possible:

| Output | Treatment |
|--------+-----------|
| Valid JSON, =verdict: APPROVE=, matching revision | APPROVE |
| Valid JSON, =verdict: APPROVE=, wrong revision | BLOCKED (stale or wrong target) |
| Valid JSON, =verdict: REQUEST_CHANGES= | REQUEST_CHANGES |
| Malformed or ambiguous JSON | BLOCKED |
| No JSON found | BLOCKED |
| Missing artifact file | BLOCKED |
| Agent exit != 0, timeout, or no output | BLOCKED |

An approval is valid only when it names the exact snapshot under review. Missing, timed-out, crashed, ambiguous, or contradictory output blocks the pipeline and is never routed as an actionable finding.

** Routing matrix

| Finding | Primary owner | Required replay |
|---|---|---|
| Requirement encoded incorrectly or incompletely in tests | test-designer | RED → implementer GREEN → both reviews |
| Duplicated fixture/helper/harness | test-designer | RED if behavior changes → GREEN → both reviews |
| Production behavior defect | implementer | GREEN → both reviews |
| Missing calculation/business coverage | test-designer for behavioral gap; implementer for local unit gap | RED when behavioral test changes → GREEN → both reviews |
| Missing or incorrect schema/spec/contract | implementer | GREEN → both reviews |
| Production duplication or misplaced abstraction | implementer | GREEN → both reviews |
| Cross-cutting mismatch between test contract and implementation boundary | both, test designer first | RED → GREEN → both reviews |

Reviewers do not repair their own findings. After any test or code change, previous approvals are stale. Both reviewers inspect the complete new revision; approval cannot be patched forward from an older diff.

* Model selection strategy

Different models have different tool-use reliability, context-window size, and reasoning depth. Assign models to roles based on their characteristics:

| Role | Needs | Suggested tier | Example models |
|------+-------+----------------+----------------|
| test-designer | Code generation, test patterns, tool use | Mid-tier | deepseek-v4-flash, claude-haiku, gpt-4o-mini |
| implementer | Deep reasoning, ACD refactoring, multi-file edits | Strong | deepseek-v4-pro, claude-sonnet-4, gpt-4o |
| correctness-reviewer | Thorough analysis, edge cases, large context | Strong | claude-sonnet-4, gpt-4o, deepseek-v4-pro |
| structural-reviewer | Pattern matching, codebase search, large context | Strong | claude-sonnet-4, gpt-4o, deepseek-v4-pro |
| flow-documenter | Diagram generation, documentation | Mid-tier | deepseek-v4-flash, claude-haiku |

When switching a role's model:

1. *Context window*: Smaller windows need trimmed context-injection instructions.
2. *Tool reliability*: Flash/light models may need more explicit tool-use guidance.
3. *Reasoning depth*: Pro/opus models handle open-ended analysis; flash models need more structure.
4. *JSON compliance*: Reviewers on weaker models may need explicit JSON schemas in their prompts. If a model consistently produces malformed JSON, demote it from reviewer roles.

* Definition of done

A workflow is done only when all statements are true:

- Original requirements are durably recorded.
- Independent behavioral tests map to requirements.
- RED was observed for the intended missing behavior.
- Relevant tests and checks are GREEN after implementation.
- Calculation/business behavior has meaningful coverage.
- Important data boundaries have appropriate specs, schemas, types, or validation.
- Test and production duplication were actively searched for and addressed appropriately.
- Correctness and structural reviewers approved the same current revision via valid JSON.
- No code changed after those approvals.
- The Draw.io diagram represents the final approved implementation and was validated.
- Durable workflow state records artifacts, commands, verdicts, decisions, and completion.

* Setup checklist

1. Run =org-babel-tangle=. It generates the =.hermes/pipeline/= files.
2. Ensure each configured model is available via the declared provider.
3. Edit =.hermes/pipeline/config.yaml= to match the project's model preferences and turn budgets.
4. Verify =hermes chat --help= confirms =--query-file=, =--oneshot=, =--worktree=, =--run-budget=, =--reasoning=, =--toolsets= are accepted.
5. Pilot on a small behavior change and inspect RED evidence, JSON verdicts, routing, dual approvals, and Draw.io output before broad adoption.
6. Keep =reviewer_parallel: false=; the orchestrator rejects automatic worktree review because it cannot represent the active dirty snapshot safely.
7. Install PyYAML if needed (=python -m pip install pyyaml=), then launch with =python .hermes/pipeline/orchestrator.py docs/spec.md=, supplying the requirements path explicitly. Repeat =--slice DESCRIPTION= for an ordered multi-slice implementation.
